## 🎓 Evidence from quantitative research

For my undergraduate dissertation, I studied climate and grain production across 13 major grain-producing provinces in China. I used R and Python to clean and align multi-source provincial data, visualise regional trends, estimate production relationships, and develop time-series forecasts.

The topic was environmental, but the analytical workflow transfers directly to content operations:

| Analytical step | Transfer to content operations |
| --- | --- |
| Align multi-source provincial data | Combine content, market, and performance data consistently |
| Check missing values and units | Validate tracking quality before interpretation |
| Compare regions and trends | Identify market-level differences and emerging patterns |
| Model relationships | Test which factors may be associated with outcomes |
| Communicate uncertainty | Avoid presenting correlation or forecasts as certainty |

This experience strengthened my ability to connect data problems with operational context rather than treating them as isolated technical errors.

## 🤖 How I use AI tools

I use ChatGPT, Claude, and Codex for structured research, content organisation, code support, and workflow improvement. My process separates speed from verification:

1. Define the audience, decision, format, and evidence standard.
2. Use AI to propose search terms, structures, code approaches, or comparison dimensions.
3. Check facts, numbers, dates, quotations, and links against original sources.
4. Validate quantitative outputs independently.
5. Review tone and cultural meaning before publication.
6. Keep confidential and personally identifiable information out of public workflows.
